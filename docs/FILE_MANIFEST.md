# File manifest

| Directory | Contents |
|---|---|
| `data/` | LTND and LTCAT datasets plus the glossary-source manifest. |
| `scripts/` | Reproducible Python procedures used in the dissertation. |
| `rdf/` | Validated SKOS/RDF samples in Turtle and RDF/XML. |

| `licenses/` | Licensing status and recommended publication options. |
| repository root | README, citation metadata, dependencies, changelog, and checksums. |
